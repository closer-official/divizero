# SNS人格OS Ver.4

## まずここから

SNS人格OSは、投稿をコンテンツでなく人格証明として運用する知識システムです。目的は販売ではなく信用の蓄積。読者へ知識でなく知的快感を届け、**「この人ならまた違う見方をくれそう」**という期待を積みます。

Ver.4はVer.3の思想を変えず、次の役割を分離しました。

|層|場所|役割|更新頻度|
|---|---|---|---|
|思想|`docs/`|人格憲法、美学憲法、全体設計|低い|
|実行|`spec/`|OS①〜⑥が何をするか|運用改善時|
|分析知識|`dictionaries/`|概念と分析方法|研究で精緻化|
|運用知識|`db/`|実例、発見、検証済みパターン|日々蓄積|

## 基本運用フロー

1. OS①が他者投稿を辞典で分析し、研究ノートとDB候補を作る。
2. OS⑤が候補を15DBへ仮登録する。
3. OS②／③が辞典と実証済みDBを参照して候補を作る。
4. OS⑥が人格・美学・辞典との整合を監査する。
5. 人間がオチ、余白、ニヤッ、投稿可否を選ぶ。
6. OS④が結果を評価し、DBの実証状態と研究課題を更新する。

## 更新ルール

- docs：反応だけで変えない。運営者承認、理由、差分、影響、検証期間が必要。
- spec：運用上の改善を反映するが憲法を変更しない。
- dictionaries：概念定義。複数の分析根拠で更新する。
- db：実例とパターン。出典必須で、仮登録／実証済み／廃止済みを区別する。

## 絶対に維持すること

投稿は人格証明。SNSは信用の蓄積。価値は知的快感。ユーモアはニヤッ。裏切りは一段。ツリーは追加1投稿まで。引用は相手肯定・相手主役。営業、論破、教育者化、専門家ぶり、煽りは禁止。

## 人間とAI

AIは構造・レンズ・認知を整理し、分析と候補を提示します。面白さを完成させません。最後のオチ、余白、ニヤッ、投稿可否、憲法改定は人間が決めます。
