# S3移行シグナル対応UI実装指示書

## 背景・変更理由

OS② Ver4.2で「S3移行」という新しい判定値が追加された。
S2（公開リプ往復）フェーズでDMに移行すべきタイミングを、以下の3シグナルで判定する：

- シグナルA：相手が公開では言いにくい本音・内部事情に踏み込んだ
- シグナルB：相手の自己開示が深まり前のめり度が上がった
- シグナルC：リプ往復が3回に達した（上限キャップ）

この判定値に対応するUIと、アプリ側のデータモデルを更新する。

---

## 実装前に必ず読むこと

1. 既存コードを読んでから書く
2. 変更ファイルを明示する
3. データモデルを先に変更してからUIに進む

## 変更1：データモデル

### 変更ファイル：`src/types/index.ts`（または型定義ファイル）

既存の `os2Judgment` の型に `'S3移行'` を追加する。

```typescript
// 変更前
type OS2Judgment = '前進' | '維持' | '休眠' | 'クローズ' | '対象再選定';

// 変更後
type OS2Judgment = '前進' | '維持' | '休眠' | 'クローズ' | '対象再選定' | 'S3移行';
```

Case または Touch の型に以下のフィールドを追加する（未存在の場合）：

```typescript
repExchangeCount: number;   // リプ往復回数（S2での公開リプ往復数）
s3Signal: 'A' | 'B' | 'C' | null;  // S3移行シグナル種別
s3SignalQuote: string;      // シグナルの根拠（相手発言の引用）
```

const s3Signal = block.match(/【S3移行シグナル】\s*(.+)/)?.[1]?.trim() ?? '';
const s3SignalQuote = s3Signal.includes('有') 
  ? s3Signal.replace(/^有[（(]/, '').replace(/[）)]$/, '')

## 変更3：OS②パイプラインタブのUI

### 変更ファイル：OS②パイプラインタブを表示しているコンポーネント

#### 3-1. 判定バッジに「S3移行」を追加

既存の判定バッジの色マッピングに追記する：

```typescript
const judgmentBadgeColor: Record<string, string> = {
  '前進': 'bg-green-100 text-green-800',
  '維持': 'bg-yellow-100 text-yellow-800',
  '休眠': 'bg-gray-100 text-gray-600',
  'クローズ': 'bg-red-100 text-red-800',
  '対象再選定': 'bg-orange-100 text-orange-800',
  'S3移行': 'bg-purple-100 text-purple-800',  // 追加
};
```

#### 3-2. 「S3移行」判定時の次アクションUI

判定が `S3移行` のとき、タッチカードまたはケースカード下部に以下を表示する：

```
┌─────────────────────────────────────┐
│ 💬 DM移行のタイミングです             │
│                                     │
│ 移行理由：{s3SignalQuote}            │
│                                     │
│ [DM会話を開始する]                   │
└─────────────────────────────────────┘
```

- 「DM会話を開始する」ボタンは既存の「💬 DM会話を開始」ボタンと同じ処理を呼び出す
- `s3SignalQuote` が空の場合は移行理由行を非表示にする

#### 3-3. リプ往復カウンターの表示

S2フェーズのケースカードに、現在のリプ往復回数と上限を表示する：

```
リプ往復：{repExchangeCount} / 3回
```

- `repExchangeCount >= 3` のとき、テキストを赤色にしてS3移行を促す

## 変更4：会話スレッドUI（本日実装中の機能との連携）

### 変更ファイル：会話スレッドコンポーネント（ClaudeCode_会話スレッド続き実装指示書.md の実装対象）

「送信完了として追加」処理の中で、リプ往復カウントを更新する際に上限チェックを追加する：

```typescript
// 「送信完了として追加」の処理内
const newRepCount = isRep ? (touch.repExchangeCount ?? 0) + 1 : (touch.repExchangeCount ?? 0);

await updateDoc(touchRef, {
  conversationTurns: arrayUnion(newTurn),
  repExchangeCount: newRepCount,
  // ...既存フィールド
});

// リプ往復3回に達したら、S3移行シグナルCをセット
if (isRep && newRepCount >= 3) {
  await updateDoc(caseRef, {
    s3Signal: 'C',
    s3SignalQuote: 'リプ往復3回上限に達しました',
    updatedAt: Timestamp.now(),
  });
}
```

スレッド下部に、リプ往復上限に近づいたら警告を表示する：

```
（repExchangeCount === 2 のとき）
⚠️ 次が最後の公開リプです。S3（DM）移行を検討してください。

（repExchangeCount >= 3 のとき）
🔴 リプ往復上限に達しました。DM移行してください。
[DM会話を開始する]
```
