【S1の目的（必ず読むこと）】
S1の目的はDM移行への布石ではなく「認知維持・関係維持」です。
「返信が来た＝DM移行」という発想を完全に捨ててください。
DM移行はDM_SCOREが80点以上かつ仮説検証価値がある（DMで自然に聞ける問いが1つ以上存在する）場合のみです。

【DM_SCORE（各案件の引き継ぎ情報内の営業期待値スコアを使って算出）】
■ 営業期待値（0〜40点）：引き継ぎ情報の値をそのまま使用
■ 関係温度（0〜30点）：0=無反応 / 5=いいね1回 / 10=いいね2回以上 / 15=テキスト返信1回 / 20=テキスト返信2回以上（累計） / 25=相互フォロー / 30=DM歓迎明示（「DMください」等）
■ 営業仮説スコア（0〜30点）：30=募集開始・新サービス / 20=LINEのみ導線・受講生あり・教育コンテンツ販売中・紹介導線のみ / 15=検索導線なし・LPなし / 0=仮説を立てる要素なし

【判定基準（DM_SCOREに基づく）】

◆ S1継続（DM_SCORE 60〜79点）
・テキスト返信あり → 返信に1〜2文で返す（営業・LP誘導なし）
・テキスト返信なし → 次の新規投稿を待ちS1を再実行
・返信がクローズ型 → 7〜30日待機し次の投稿で再接触
→ S1継続は正常な認知維持ループ状態

◆ DM移行（DM_SCORE 80点以上 かつ 仮説検証価値がある）
→ 返信だけではDM移行しない。仮説検証価値がある＝DMで自然に聞ける問いが1つ以上存在する（営業仮説スコアが0点でないこと）。
→ 例：「LINEだけなのは意図的ですか？」「受講生からLPの相談って来ますか？」など、営業色なく事業理解を深められる質問が成立する場合。DMの目的は「営業」ではなく「仮説検証」。

◆ 次投稿再接触（DM_SCORE 40〜59点、または営業期待値35点以上で低反応の場合）
→ いいね・スタンプのみ、または仮説スコアが低い
→ 次の新規投稿を待ち別の具体点で再接触

◆ 休眠（営業期待値34点以下 かつ DM_SCORE 39点以下 または 無反応3回以上連続）
→ 営業期待値35点以上の超優良案件は反応がゼロでも休眠に移行しない（次投稿再接触を維持）。
→ 低頻度監視へ移行。追いS1はしない。
→ 再開条件：新しい事業展開・仮説検証機会が生まれたと判断できるとき

◆ 保管（長期アーカイブ、営業期待値34点以下の案件のみ）
→ 営業期待値35点以上の超優良案件は保管に移行しない（次投稿再接触を維持）。
→ 完全無反応3連続または30日以上反応ゼロ
→ 再接触トリガー：半年後または大きな変化のみ

◆ クローズ
→ 公開拒絶（R5）またはこの案件を終了する
