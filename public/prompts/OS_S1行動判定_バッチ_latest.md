【S1の目的（必ず読むこと）】
S1の目的はDM移行への布石ではなく「認知維持・関係維持」です。
「返信が来た＝DM移行」という発想を完全に捨ててください。
DM移行はスコア合算ではなく条件式で判定します。UTAGE優先か通常かで条件が異なり、どちらも仮説検証価値が前提です。

【DM移行条件】
■ 営業対象判定：対象外ならDM不可
■ 関係温度（0〜30点）：0=無反応 / 5=いいね1回 / 10=いいね2回以上 / 15=テキスト返信1回 / 20=テキスト返信2回以上（累計） / 25=相互フォロー / 30=DM歓迎明示（「DMください」等）
※複数段階に該当する場合は、最も高い1段階のみを採用する（加算しない）。
※累計値（いいね累計回数・テキスト返信累計回数）は入力に含まれる値のみを使う。入力に無い場合は連続数から推定せず、低い方の段階を採用する。
■ 営業仮説スコア（0〜30点）：30=募集開始・新サービス / 20=LINEのみ導線・受講生あり・教育コンテンツ販売中・紹介導線のみ / 15=検索導線なし・LPなし / 0=仮説を立てる要素なし（ただし提携候補フラグ＝有の場合は0点にしない。「受講生がいる」として20点を適用）
※複数段階に該当する場合は、最も高い1段階のみを採用する（加算しない）。
※厳命：上記4段階（30 / 20 / 15 / 0）以外の数値（25点・10点・5点など）を出力することを固く禁じる。必ずいずれかの定義値を選ぶこと。

◆ S1継続

→ S1継続は正常な認知維持ループ状態

◆ DM移行
→ 返信だけではDM移行しない。仮説検証価値がある＝DMで自然に聞ける問いが1つ以上存在する（営業仮説スコアが0点でないこと）。
→ UTAGE優先案件：営業対象判定が対象、案件適合度が高または中、関係温度15以上でDM移行可。
→ 通常案件：営業対象判定が対象、案件適合度が高、関係温度25以上でDM移行可。
→ DMの目的は「営業」ではなく「仮説検証」。

【DM1通目で投げる仮説の4パターン（必ずいずれかに分類する）】
A（導線仮説）：導線設計の「意図」を確認。例：「LINE一本で回されているのが凄いなと思ったのですが、あの導線はあえて意図的なんですか？」
B（運用仮説）：ツール・運用コストの意図を確認。例：「UTAGE一本で綺麗にまとまっていますが、意図的にUTAGEだけにされているんですか？」
C（受講生仮説）：受講生・第三者の課題を確認（最優先ルート）。例：「受講生さんから、LPやホームページ周りの相談って結構来たりしませんか？」
D（紹介仮説）：紹介経路の設計を確認。例：「紹介で来られた方って、一番最初はどこを見てもらうように設計されているんですか？」

【DM1通目の絶対禁止事項】
❌「LPを作る予定はありますか？」❌「導線を整理・改善する予定はありますか？」❌「〜を導入しませんか？」「〜のお手伝いができます」
