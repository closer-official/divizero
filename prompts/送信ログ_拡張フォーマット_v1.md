# 送信文章ログ（拡張フォーマット v1）

> 目的：送った文章だけでなく「どの投稿に送ったか（対象選び）」までを記録し、
> 　　　【対象妥当性】と【文面妥当性】を別々に評価する。
> 　　　Rin案件の教訓＝「トーン合わせ以前に対象選びで死ぬ」を構造的に拾うための監査ログ。
>
> 二軸を必ず分ける理由：文面だけ見ると良くても、貼る先（対象）を外すと死ぬ。
> 　例）Rin「機会損失の方がデカいやつじゃないですか」＝文面は△〜◯／対象は✕（愚痴ツイートに営業意図）。
> 　二軸を混ぜると「文がダメだったのか対象がダメだったのか」が永遠に切り分けられない。

---

## 【記入テンプレート】（1接触ごとにこのブロックを複製）

```
## ◯◯（@handle）— 媒体（Instagram / X / Threads）

### [送信N] 案X — YYYY-MM-DD

▼接触対象（このメッセージを「どの投稿に」送ったか）
　対象本文：（引用 or 1行要約）
　種別：課題 / 通常投稿（ノウハウ・実績・告知）/ 達成・嬉しい報告 / 愚痴・本音 / ネタ
　鮮度（X・Threadsは必須）：投稿から◯時間 / ◯日（3日以上前は「掘った業者」化リスク）
　トラック整合：FT課題に乗れてる / NT通常投稿に乗れてる / ✕非課題に営業意図で乗った
　接触チャネル：投稿コメント / リプライ / 公開返信 / ストーリー返信 / DM

▼元の文章（AI生成）
　（OS①の出力をそのまま）

▼実際に送った文章（編集済み / 元のまま）
　（実送信文）

▼編集理由
　（なぜ直したか。複数あれば箇条書き）

▼【対象妥当性】◯ / △ / ✕ ＋一言
　（この投稿に営業意図で接触してよかったか。✕なら何に乗るべきだったか）

▼【文面妥当性】◯ / △ / ✕ ＋一言
　チェック観点（該当を明記）：
　・祝福の出しどころ：場が祝福一色か（OKの祝福）/ 場違いな祝福（NG）/ 該当なし
　・禁止語・評価語の復活：編集で「すごい/勉強になります」等が戻っていないか
　・鉤括弧：「」『』""で囲っていないか（地の文になっているか）
　・独白化：ストーリー返信が独白でなく相手宛ての感想になっているか（IG）
　・投稿アンカー：自分しか言わない具体の一点が入っているか（貼り替えテスト）

▼（任意）相手反応 → OS②/OS③へ連結
　（いいね返り / 返信 / 無反応 / 公開拒絶 等。判定に回すなら案件IDを併記）
```

## 【評価の早見】

対象妥当性：
- ◯＝課題/通常投稿/達成報告に乗った
- △＝グレー（課題か愚痴か曖昧）。X・Threadsでは△は原則見送り寄り
- ✕＝愚痴・本音・ネタの単発に営業意図で乗った（＝Rin型。最重要の失点）

文面妥当性：
- ◯＝アンカー有・禁止語無・鉤括弧無・トーン一致
- △＝軽微（絵文字の有無、語尾の硬さ等。送信に支障はないが要観察）
- ✕＝禁止語/評価語の復活・業者リフレーム・独白・没個性（貼り替えテスト落ち）

※「対象✕・文面◯」が一番危険。文がうまいほど営業臭が際立って晒されやすい。
　対象✕が出たら、文面の良し悪しに関係なく「対象を変えろ」が唯一の正解。

## 【記入例】（既存ログを変換）

## Rin🍎通帳の刑 / iPhone修理物販コンサル講師（@Ringo_diary23）— X

### [送信1] リプライ — 2026-06-19

▼接触対象（このメッセージを「どの投稿に」送ったか）
　対象本文：「エアコン代ケチってたら今日暑くて部屋が30度になってて体調悪くなっちまった／もうこの季節だと夜にエアコン入れておかないとダメだな」
　種別：愚痴・本音（体調・プライベートのつぶやき）
　鮮度：投稿から9時間（鮮度はOKだが、それは問題ではない）
　トラック整合：✕非課題に営業意図で乗った（アカウントはNT、ツイートは業務課題ですらない個人の愚痴）
　接触チャネル：リプライ

▼元の文章（AI生成）
　30度の部屋で仕事してた…？／電気代より機会損失の方がデカいやつじゃないですか

▼実際に送った文章
　（元のまま送信）

▼編集理由
　なし（無編集で送信）

▼【対象妥当性】✕
　愚痴ツイートに営業意図で接触した。乗るべきではなかった。乗るなら共感一言（例：夜のエアコンもう必須ですよね）のみ、ビジネス要素ゼロ。本来は同アカウントの業務・ノウハウ投稿を対象に切り替えるべきだった。

▼【文面妥当性】△
　・投稿アンカー：有（30度・電気代に具体で乗ってはいる）
　・禁止語：「機会損失」＝実質マーケ用語のリフレーム。観察者・ビジネス目線が露出 → ✕寄り
　・鉤括弧：無（ここは問題なし）
　文として崩れてはいないが、愚痴に対してビジネスのリフレームをかぶせた時点で文面も営業臭。対象✕と相まって致命傷。

▼相手反応 → OS②/OS③へ連結
　公開コメ返で「ai返信マジでやめた方がいいですよ」＝R5公開拒絶。案件ID：ringo-20260620／OS③検証済み（TypeC営業警戒・行動根因TypeG）。
　※コメ返で済んだのは相手の温情であり、晒され得る距離での公開拒絶。レッドカード扱いは変えない。

　「口座残15で高額スクール即決、しかもそこから42日で360万って、覚悟の入れ方が完全に別次元ですね。破産してる時に逃げじゃなく攻めの選択できるの、なかなかできないと思う」

　・鉤括弧：編集で除去済み（◯）。新OS①では生成時点で括弧が付かないため、今後この手直しは不要。

　「ブルバなしで2827万インプって、バズ狙いじゃなくて届く人に届く発信になってるってことですよね。数字より先に設計がある、って順番が逆の人ほんと多い」

　・投稿アンカー：有（2827万インプ・ブルバなしに具体で乗れている）

　・自分要素：「自分含めて」で観察者化を回避できている（◯の編集）。

> 運用メモ：
> - 「対象妥当性✕」が month単位で複数出るなら、それは文章力の問題ではなく「対象選び（OS⓪/OS①の入口）」の運用問題。OS③の学習価値の高い失注がそこに固まる。
> - 「文面妥当性」で同じ指摘（鉤括弧・独白・評価語復活）が繰り返し出るなら、OS①生成ルールにまだ穴がある合図。フォーマットがOS①へのフィードバック経路になる。
