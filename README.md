# SNS人格OS Ver.3

> 「バズる投稿を真似することではなく、フォローされる人格を研究すること」

---

## このプロジェクトとは何か

**SNS人格OS Ver.3** は、SNS上での人格運用を体系化した、AI支援型の人格・投稿管理システムの完全仕様書である。

これは投稿生成ツールの説明書ではない。  
これはプロンプト集でもない。  
これは **人格という有機体を研究・維持・進化させるためのオペレーティングシステム群の仕様書** である。

分析対象は「文章」ではなく「人格」。  
観察対象は「投稿」ではなく「認知変化」。  
目的は「注目を集めること」ではなく「フォローされる存在になること」。

---

## 設計思想

### なぜ「OS」という概念を使うのか

通常のプロンプトは「一度使い捨て」の命令書である。  
しかし本システムが扱う対象は、半年〜数年にわたって継続運用される「人格」という動的な存在である。

人格は固定されていない。成長し、変化し、時に逸脱する。  
それを正確に監視・維持・進化させるためには、単なるプロンプトではなく、**明確な入力仕様・処理フロー・判定基準・自己監査機能・保守方法を持つ「OS」** が必要である。

### 最上位憲法の概念

本システムには2つの最上位憲法が存在する。

```
人格辞書（01_personality_constitution.md）
        ↓
美学辞書（02_aesthetic_constitution.md）
        ↓
各OS仕様書（os01〜os06）
```

**全OSは必ずこの優先順位に従う。**  
OSの処理結果が憲法と矛盾した場合、OSは出力を差し戻し、憲法に従った再処理を行わなければならない。

## OS一覧と責務

| OS | ファイル | 主責務 | 主な入力 | 主な出力 |
|---|---|---|---|---|
| OS① | os01_analysis.md | 他者の投稿・人格を分析する | 他者のSNS投稿テキスト | 人格分析レポート・レンズ候補 |
| OS② | os02_quote.md | 引用RTを生成する | 引用対象投稿・引用角度指示 | 引用RT文・採点結果 |
| OS③ | os03_post.md | オリジナル投稿を生成する | テーマ・感情・投稿タイプ指示 | 投稿文・採点結果 |
| OS④ | os04_pdca.md | 自己投稿をPDCA分析する | 過去投稿群・エンゲージメントデータ | 改善提案・パターン抽出 |
| OS⑤ | os05_lens.md | レンズを構築・管理する | 分析から得られたレンズ候補 | レンズDB更新・適用手順 |
| OS⑥ | os06_personality.md | 人格の一貫性を監視・維持する | 直近の投稿群・OS出力群 | 人格逸脱アラート・修正指示 |

## 使い方

### 初回セットアップ

1. `docs/01_personality_constitution.md` を読み、自分の人格情報を全セクションに記入する
2. `docs/02_aesthetic_constitution.md` を読み、自分の美学情報を全セクションに記入する
3. `docs/00_project_overview.md` を読み、システム全体の設計を理解する
4. 各OS仕様書を読み、AIへの指示方法を理解する

### 日常運用

```
毎日：
  - OS①で他者投稿を分析し、レンズを更新する（OS⑤に連携）
  - OS②でリアクション価値の高い投稿に引用RTを作成する
  - OS③でオリジナル投稿を生成する

週次：
  - OS④で週間PDCA分析を実施する
  - OS⑥で人格維持チェックを実施する

月次：
  - OS⑤でレンズライブラリをレビュー・整理する
  - 人格辞書・美学辞書を必要に応じて更新する
```

### AIへの指示方法

各OS仕様書の冒頭には「AIへの入力テンプレート」がある。  
AIに渡す際は以下の構造で渡す：

```
[人格辞書の該当セクション]
[美学辞書の該当セクション]
[OS仕様書の全文 または 該当OS名の明示]
[実際の入力データ]
```

## 優先順位の原則

本システムにおける全ての判断は以下の優先順位に従う：

```
優先度1：人格辞書（01_personality_constitution.md）
優先度2：美学辞書（02_aesthetic_constitution.md）
優先度3：各OS仕様書の個別ルール
優先度4：AIの推論・補完
```

優先度1と優先度3が矛盾した場合、**必ず優先度1が勝つ**。  
AIはこの原則を自己監査の第一チェック項目として扱わなければならない。

## 用語定義

| 用語 | 定義 |
|---|---|
| **人格（Personality）** | SNS上に投影される思想・価値観・語り方・関係性パターンの総体 |
| **認知変化（Cognitive Shift）** | 投稿を読んだ後にフォロワーの認識・思考が変化すること |
| **レンズ（Lens）** | コンテンツや人格を分析するための特定の視点・フレームワーク |
| **レゾナンス（Resonance）** | 投稿がターゲット読者の内的状態と共鳴する度合い |
| **温度（Temperature）** | コンテンツや関係性の感情的な熱量・親密度 |
| **人格逸脱（Personality Drift）** | 人格辞書の定義から投稿スタイル・思想が外れていく現象 |
| **人格辞書（Personality Constitution）** | 運営者のSNS人格を定義した最上位の文書 |
| **美学辞書（Aesthetic Constitution）** | 運営者の表現美学を定義した第二位の文書 |
| **OS** | 特定の処理を担うオペレーティングシステム。入力・処理・出力が明確に定義される |
| **自己監査（Self-Audit）** | AIが出力前に、自分の出力が仕様に準拠しているかチェックするプロセス |
| **PDCA** | Plan（計画）→ Do（実行）→ Check（分析）→ Action（改善）の改善サイクル |

## ライセンス・使用条件

本仕様書は運営者個人の人格運用のために設計されたものである。  
人格辞書・美学辞書の内容は運営者固有の情報であり、第三者への共有は運営者の判断に委ねる。  
OS仕様書の構造自体は改変・拡張自由であるが、改変した場合は必ずバージョン番号を更新し変更履歴を記録すること。
